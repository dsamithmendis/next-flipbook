# Examples

The runnable examples live in the Next.js demo app: `demo/next-app/app`.

| Route | Shows |
| --- | --- |
| `/` | Server Component passing plain data to `FlipBook` |
| `/images` | Cover mode, auto single/double |
| `/single` | Single page, dark theme, strong shadows |
| `/custom-pages` | React pages mixed with images |
| `/rtl` | Right-to-left book |
| `/features` | Toolbar, thumbnails, bookmarks, fullscreen, download, print, share |
| `/search` | Search, the PDF's contents and its links |
| `/hotspots` | Hotspots with popovers and links, and an overlay |
| `/deep-links` | The page in the address bar, and a saved reading place |
| `/large-pdf` | A generated 100, 500 or 1000 page PDF, with live cache and memory figures |

Run them with `npm run dev` from the repo root.
